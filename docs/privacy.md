# Политика конфиденциальности Forganizer

Forganizer помогает разложить файлы в выбранной папке на устройстве.

## Какие данные обрабатываются

- Для анализа на сервер приложения и в сторонние ИИ-сервисы (OpenRouter, Groq) отправляются только **метаданные** файлов из корня выбранной папки: имена, расширения, размеры, даты изменения и имена существующих папок.
- **Содержимое файлов не читается и не отправляется.** Поиск дублей (хэширование содержимого) выполняется только на устройстве.
- Сервер не хранит запросы и ответы ИИ и не записывает их в логи. Записываются только технические метрики: размер запроса, длительность, использованная модель, код ответа.

## Что хранится на устройстве

- Журнал перемещений (для отмены) и настройки. Их можно удалить в настройках кнопкой «Очистить данные».

## Согласие

Перед первым запросом приложение запрашивает согласие на отправку имён файлов. Согласие можно отозвать в настройках.

## Разрешения

- «Доступ ко всем файлам» (версия full) используется только для просмотра и перемещения пользовательских файлов по явной команде пользователя. Приложение ничего не удаляет.
